# Contributing to awesome-AI-agents

Thank you for your interest in contributing!

## How to Contribute

### Adding New Items

1. Check the existing list to avoid duplicates
2. Add items in the appropriate category section
3. Include: name, description, and URL
4. Keep descriptions concise (1-2 sentences)

### Categories

- **🤖 Agents** - AI agent frameworks (open source & commercial)
- **🔧 Tools** - Developer tools, SDKs, infrastructure
- **📚 Resources** - Communities, documentation, newsletters
- **📖 Learning** - Tutorials, courses, guides

### Pull Request Guidelines

1. **Be relevant** - Only add AI agent-related resources
2. **Be current** - Ensure links still work
3. **Be descriptive** - Write clear, concise descriptions
4. **Be balanced** - Include both open source and commercial options
5. **Sort alphabetically** - Within each category

### Submission Format

```markdown
| [Name](URL) | Description | [Stars/License] |
```

For Tools and Learning sections, use simplified format:
```markdown
| [Name](URL) | Description |
```

## Quality Standards

- No broken links
- No AI-generated spam submissions
- Prefer established projects with active communities

---

Questions? Open an issue to discuss before submitting.
