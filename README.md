# awesome-AI-agents

> A curated list of AI Agent frameworks, tools, platforms, and learning resources.

## What is an AI Agent?

An AI Agent is an autonomous system that can perceive its environment, reason about goals, take actions, and learn from outcomes. Unlike simple chatbots, agents can plan, use tools, and execute multi-step tasks.
